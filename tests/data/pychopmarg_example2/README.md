# PyChOpMarg "Example 2" channel data

`example2_THRU.s4p`, `example2_FEXT1.s4p`, `example2_FEXT2.s4p`,
`example2_NEXT1.s4p`, `example2_NEXT2.s4p`, `example2_NEXT3.s4p` are real,
measured 4-port Touchstone files (VITA 68.2), copied verbatim from
[PyChOpMarg](https://github.com/capn-freako/PyChOpMarg)'s own
`chnl_data/` directory — the channel set behind "Example 2" in
`notebook/PyChOpMarg.ipynb`.

Used by `tests/evaluate/test_pychopmarg_example2.py` as this project's
one golden test against real (not synthetic) channel data.
